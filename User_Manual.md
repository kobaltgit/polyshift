# 📖 Руководство пользователя: Gemini AI Переводчик

Добро пожаловать в **Gemini AI Переводчик** — мощную и элегантную утилиту для мгновенного перевода текста в любом приложении Windows с использованием передовых моделей Google Gemini.

---

## 🚀 Быстрый старт

### 1. Получение API Ключа
Для работы программы вам понадобится ключ API Google Gemini.
1. Перейдите в [Google AI Studio](https://aistudio.google.com/app/apikey).
2. Создайте новый API ключ.
3. Скопируйте его.

### 2. Первичная настройка
1. Запустите программу.
2. Нажмите на ссылку **"НАСТРОЙКИ КОНФИГУРАЦИИ"** в главном окне.
3. Вставьте ваш ключ в поле "GEMINI API КЛЮЧ" (вы можете использовать кнопку **"ВСТАВИТЬ"**).
4. Выберите желаемую модель из списка (рекомендуется `gemini-1.5-flash` для скорости или `gemini-1.5-pro` для максимального качества).
5. Нажмите **"СОХРАНИТЬ ИЗМЕНЕНИЯ"**.

---

## 🛠 Использование

### Мгновенный перевод (Hotkeys)
Самый быстрый способ перевести текст:
1. Выделите любой текст в любом приложении (браузер, PDF-ридер, мессенджер).
2. Нажмите комбинацию клавиш **`Alt + T`**.
3. В правом нижнем углу появится элегантное окно с результатом перевода.

> [!TIP]
> Текст перевода **автоматически копируется** в буфер обмена сразу после появления. Вы можете сразу вставить его в нужное место с помощью `Ctrl + V`.

### Фоновый режим и Трей
Программа создана для того, чтобы не мешать вашей работе:
- После настройки главное окно можно закрыть — программа свернется в **системный трей** (рядом с часами).
- Чтобы вызвать главное окно снова, дважды кликните по иконке Gemini в трее или выберите "Развернуть" в контекстном меню.

---

## 🎨 Интерфейс HUD (Glass Effect)
Всплывающее окно перевода (HUD) обладает эффектом матового стекла и автоматически исчезает, когда вы переключаете фокус на другое окно. 
- Нажмите на крестик в углу или просто кликните в любом другом месте, чтобы закрыть его.

## ❓ Решение проблем

| Проблема | Решение |
| :--- | :--- |
| **Ошибка API Key** | Проверьте, правильно ли вставлен ключ и не истек ли его срок действия. |
| **Текст не захватывается** | Убедитесь, что текст выделен перед нажатием `Alt + T`. Некоторые защищенные приложения могут блокировать системные хуки. |
| **Список моделей пуст** | Убедитесь, что API ключ введен верно и у вас есть доступ к интернету. |

## 🛡 Безопасность и Конфиденциальность
Программа использует официальный Google Gemini API. Ваши данные передаются напрямую в Google для обработки и не сохраняются локально, кроме самого API ключа, который хранится в зашифрованном/защищенном виде в файле `config.json`.
