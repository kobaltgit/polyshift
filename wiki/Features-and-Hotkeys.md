# ⚡ Горячие клавиши и действия

PolyShift работает в фоновом режиме в системном трее Windows и перехватывает глобальные сочетания клавиш при помощи нативного Win32 API (`RegisterHotKey`).

---

## 🎹 Сводная таблица горячих клавиш

| Сочетание | Действие | Описание |
| :--- | :--- | :--- |
| **`Alt + T`** | **Умный перевод** | Мгновенный перевод выделенного фрагмента текста на выбранный язык (по умолчанию — Русский). Если текст уже на русском, переводит на английский. |
| **`Alt + G`** | **Грамматика и стиль** | Исправление опечаток, пунктуационных ошибок и стилистическое улучшение тона текста. |
| **`Alt + S`** | **Суммаризация** | Краткая выжимка ключевых смыслов длинной статьи, фрагмента документации или письма. |
| **`Alt + E`** | **Анализ и объяснение** | Разбор терминов, сложного фрагмента кода, формулы или концепции простым языком. |
| **Зажатие ЛКМ за заголовок** | **Перемещение окна** | Зажмите заголовок окна слева от кнопок и перетащите оверлей в любое место экрана. |
| **`Esc`** | **Скрыть оверлей** | Мгновенно закрывает плавающее окно HUD при активном фокусе. |
| **`Ctrl + C`** | **Копировать результат** | Копирует сгенерированный перевод или анализ в буфер обмена (если выключено автокопирование). |

---

## 🔄 Как это работает под капотом

1. При нажатии горячей клавиши PolyShift сохраняет текущее положение курсора мыши.
2. Через Windows Win32 `SendInput` нажимается системная комбинация `Ctrl + C`, и выделенный фрагмент текста считывается из буфера обмена.
3. Окно HUD плавно появляется прямо возле курсора мыши (`GetCursorPos`).
4. Начинается потоковый SSE-запрос к Google Gemini API.
5. Токены ответа отображаются в окне в реальном времени с поддержкой Markdown-разметки.
6. При включённой опции «Автокопирование» результат автоматически помещается обратно в буфер обмена.
