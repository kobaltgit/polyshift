# 🌐 PolyShift Wiki

Добро пожаловать в официальную документацию **PolyShift** — сверхбыстрого и легковесного ИИ-ассистента для Windows 10/11.

PolyShift позволяет мгновенно переводить, улучшать стиль, суммаризировать и объяснять любой выделенный текст в любых приложениях Windows по глобальным горячим клавишам без переключения контекста.

---

## ⚡ Быстрый старт

1. **Скачайте** актуальную версию:
   - Инсталлятор: `PolyShift_2.0.0_x64-setup.exe`
   - Портабельная версия: `PolyShift-v2.0.0-Portable-x64.zip`
2. **Запустите** приложение — иконка PolyShift появится в системном трее Windows.
3. Откройте **Настройки** из меню трея и вставьте ваш бесплатный ключ [Google Gemini API](https://aistudio.google.com/app/apikey).
4. Выделите любой текст в браузере, коде, PDF или мессенджере и нажмите **Alt + T**!

## 💡 Философия проекта

* **Молниеносная реакция**: Никаких тяжелых браузерных движков в фоне — нативный Rust-процесс потребляет всего **~12–18 МБ RAM**.
* **Никаких промежуточных серверов**: Запросы отправляются напрямую с вашего ПК на официальные эндпоинты Google Gemini API по защищённому TLS-каналу.
* **Приватность на уровне ОС**: Ваш API-ключ защищён криптографическим модулем Windows DPAPI и привязан к вашей локальной учетной записи.
